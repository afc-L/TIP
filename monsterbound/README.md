# Monsterbound — Legends of Aether

An original, full-length creature-collecting RPG for the browser, in the spirit of classic handheld
monster-catching games. Explore two regions, collect 344 original creatures, earn 14 badges/seals,
uncover the secret of Mega Evolution, stop the Eclipse Syndicate, and take on a large postgame.

All art, music and content are generated by code. There are no external assets, libraries or servers.

## Running it

**Double-click `index.html`.** That's it. It runs from `file://` with no install, no build step and no
internet connection, so it works on a locked-down school MacBook in Safari, Chrome or Firefox.

(You can also serve the folder with any static server, e.g. `python3 -m http.server`, and open
`http://localhost:8000/monsterbound/`.)

Progress is saved in the browser's localStorage (3 save slots). Saving happens when you choose
**Save**, when you heal at a Healing Center, when you change maps (autosave), and when you close the tab.

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Move / navigate menus |
| Z / Enter / Space | Interact, confirm |
| X / Esc / Backspace | Back, open the main menu |
| Shift (hold) | Run (after you get the Trail Shoes) |
| I | Bag |
| C | Party |
| M | Region map (and Fly, once you have the Wing Whistle) |
| P | Aetherdex |
| Q / J | Quest journal |
| R | Rift Lens: shift between Bright and Gloam phases (Veloria) |

In battle: pick **FIGHT** and choose a move. When your creature holds its Aether Stone and you
have the Aether Gauntlet, a **MEGA EVOLVE** toggle appears under the moves. Turn it on, then attack.

## What's in the game

- **344 original creatures** (246 in Aetheria, 98 in Veloria), each with procedural pixel-art,
  type(s), base stats, abilities, learnset, egg moves, habitat, rarity, encounter conditions and
  a Dex entry. 22 legendary, mythical and secret creatures live in their own locations.
- **48 Mega Evolutions**, each with a redesigned sprite, new stats, a possible type change, a new
  ability, a transformation sequence, a battle banner and its own sound. Aether Stones are found
  in the story, hidden caves, quests, rematches, postgame areas and the Battle Frontier.
- **15 types**, **~300 moves**, **60+ abilities** with real effects, 7 status conditions, weather,
  stat stages, critical hits, multi-hit, priority, drain/recoil, protect, pivoting and more. Trainers
  use smart AI that switches out, uses items, and Mega Evolves its ace.
- **Evolution by** level, item, friendship, time of day, location, the Bond Cord (the trade
  stand-in), quests, and branching paths.
- **Two regions.** Aetheria has 20 major locations plus routes, forests, multi-floor caves, islands,
  an underwater kingdom and secret areas. Veloria has 16 locations and a unique rift-phasing mechanic.
- **8 gyms with puzzles** (hedge maze, electric gates, boulder pushing, slick floors, lava, warp
  pads, ice sliding, a pitch-black maze), the Elite Championship, and 6 Velorian Warden challenges
  plus the Veloria League.
- **Story**: 15 chapters following the rival Kael, Dr. Lyra's Mega Evolution research, the Eclipse
  Syndicate's four commanders and their leader, the twin dragons of Dawn and Dusk, then Neo Eclipse in
  Veloria and a secret final boss in the Forgotten Expanse.
- **77 side quests**, **38 achievements**, a completion percentage, Aetherdex milestone rewards and
  an 8-shard secret-legendary hunt spanning both regions.
- **Breeding**: a Day Care, compatibility, Eggs that hatch as you walk, inherited moves and
  potential (IVs), hidden abilities, Radiant (shiny) variants and an egg-only species.
- **Postgame**: Veloria, gym, rival and champion rematches, roaming legendaries, the Battle Tower,
  Elemental Arena, Survival Gauntlet, Champion's Challenge and Legendary Trial, and a BP exchange.
- **A living world**: a day/night cycle, 4 seasons, dynamic weather, NPC schedules, daily events
  (outbreaks, traveling merchants, meteor showers, festivals, tournaments, legendary sightings and
  glittering rare items).
- **Procedural chiptune** music for every area and battle type, sound effects, creature cries, and
  volume settings.

## Project layout

```
monsterbound/
  index.html            entry point (plain <script> tags, works from file://)
  css/style.css
  js/core/              util (seeded RNG, colour), input, audio (chiptune engine), save
  js/data/              types, moves, abilities, creatures (data-driven lines -> species),
                        items/shops, trainers, world specs (Aetheria, Veloria), story, quests
  js/gfx/               procedural creature sprites, tiles/buildings, characters, battle BGs
  js/world/             mapgen (seeded route/town/cave/gym generators), world runtime, overworld
  js/battle/            creature instances, battle engine + scene, systems (bag, dex, breeding,
                        achievements, battle orchestration), Battle Frontier
  js/ui/                UI toolkit and scenes, menus (party/summary/bag/PC/shop), screens
  tools/                Node + Playwright test tools (validator, fuzzers, bot playtester)
```

### Adding content

Everything is data-driven:

- **A creature line**: add a row to `MB.LINES_AETHERIA` / `MB.LINES_VELORIA` in
  `js/data/creatures.js`. Stats, learnset, abilities, Dex text and sprite are derived from it.
  Add `mega:Type1/Type2:ability` to give the final stage a Mega Evolution. Its stone item is created
  automatically.
- **A move**: add a line to `MB.MOVE_TEXT` in `js/data/moves.js` (`Name|power|acc|P/S/X|pp|effects`).
- **A map**: call `T()` / `R()` / `F()` / `C()` in a world file, then `link()` or `portal()` it to a
  neighbour. NPCs, trainers, items, gates and triggers go in the spec.
- **A quest**: add a `Q()` / `A()` entry in `js/data/quests.js`.
- **A story beat**: add an async function to `MB.SCRIPTS` in `js/data/story.js` and reference it
  from an NPC's `script` field.

## Testing tools

Run these from inside `monsterbound/`. They need Node, plus Playwright for the browser tests.

```bash
node tools/validate.cjs                # builds every map; checks connectivity, references, obtainability
node tools/battle_fuzz.cjs 400         # 400 randomized AI-vs-AI battles
node tools/scripts_test.cjs            # runs every story/quest/facility script with auto-input
node tools/bot.cjs /tmp/bot            # a bot plays from the lab to the first badge
node tools/duel.cjs emberfox 5 ramkin 4 200   # matchup win-rate simulator
```
